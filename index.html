Миниатюра идёт отдельным потоком 960×540, 30 FPS, без звука и управления; основной поток сохраняет ваши разрешение, FPS и битрейт.

Отдельные окна мониторов. Каждый физический монитор можно открыть в своём окне; смена экрана в одном окне не трогает остальные. Права доступа к экранам проверяются для каждого окна.

Меню сеанса и переключение. Боковые разделы «Экраны» и «BeamPiP», основные действия в корне меню. Быстрые повторные выборы монитора больше не теряются. Буфер обмена не задерживает сеанс. Окно EasyTier не опрашивает диск, пока закрыто.

Исправление в клиенте 2.1.3. Выбранное разрешение и FPS снова видны на главной странице при любом поддерживаемом размере окна. Если места мало, строка переносится. Это параметры следующего подключения; фактический FPS доступен в статистике сеанса.

Быстрее подключение. Beam запоминает проверку декодера и звука для вашей системы: повторное подключение на тестовом ПК — 2,1 с вместо 2,8 с до первого кадра, при той же картинке и том же FPS. После обновления драйвера, смены монитора или звукового устройства проверка выполняется заново.

Актуальный комплект: сервер и клиент Windows 2.2.3, Android 2.2.2 и Beam Connect 0.1.6 для Windows. Изменения служебной нагрузки проверены автоматически; новые замеры игровых сеансов через Wi-Fi и интернет не проводились.

Как подключиться и обновить Beam

Перед обновлением Windows завершите сеанс и отключите Beam Connect на обновляемом ПК. Запустите общий установщик Beam 2.2.3 поверх прежнего и выберите сервер 2.2.3, клиент 2.2.3 или оба компонента. Для интернета выберите компонент Beam Connect в установщиках или обновите отдельный модуль до 0.1.6. Обновите оба Windows-компьютера. Android остаётся 2.2.2. Пользователей и профили удалять не нужно; APK можно поставить поверх прежнего Beam.

  1. Подготовьте сервер. В установщике отметьте «Интернет через Beam Connect». В веб-панели «Интернет» нажмите «Создать сеть»: Beam подберёт доступные узлы с наименьшей измеренной задержкой, сохранит настройки и включит Beam Connect.
  2. Вход по ID. Передайте девятизначный ID из раздела «Интернет» сервера. В клиенте нажмите «Добавить компьютер», введите ID и затем обычные логин и пароль Beam. Android 2.2.2 также принимает ID в «+» на главном экране (Android 7.0+).
  3. Либо используйте приглашение. Для Android или входа без ID нажмите «Скопировать ссылку» в веб-панели и импортируйте приглашение в настройках клиента «Интернет через Beam Connect». При входе по ID на Windows или Android 2.2.2 этот шаг пропускается.
  4. Подключите сеть. На Windows выберите компонент Beam Connect в установщике; на Android он уже встроен. Подтвердите системное разрешение на создание адаптера или VPN.
  5. Начните сеанс. Дождитесь маршрута, нажмите «Добавить сервер в Beam» и используйте обычный вход или PIN-сопряжение.

Общие узлы помогают устройствам найти друг друга. По возможности соединение идёт напрямую; иначе доступность и скорость зависят от ретранслятора. Android допускает один VPN в профиле. После смены сети может потребоваться повторное подключение. Приглашение храните в секрете.

Ограничение ID. ID публичный, и ключ сети выводится из него. Знающий ID может присоединиться к туннелю; пароль Beam защищает вход в сеанс, но остаётся риск вмешательства в DHCP/маршруты и отказа в обслуживании. Используйте уникальные пароли. Для закрытой группы выбирайте секретное приглашение.

Moonlight и iPhone. В веб-панели скачайте конфигурацию для отдельного приложения EasyTier, импортируйте её и добавьте VPN-адрес сервера в Moonlight. Первое сопряжение iPhone рекомендуется выполнить в домашней сети; работа на физическом iPhone ещё проверяется.

Что устанавливать: сервер или клиент?

Общий установщик Beam позволяет выбрать сервер, клиент или оба компонента. Сервер нужен компьютеру, чей экран вы хотите видеть, а клиент — устройству, с которого будете подключаться. Отдельные установщики доступны в дополнительном разделе.

Можно подключиться через VPN?

Да, когда между устройствами есть сетевой доступ. Если сервер не появился автоматически, добавьте его по IP. Для автоматического обнаружения между подсетями может потребоваться ретрансляция mDNS на роутере.

Можно использовать Moonlight?

Да. В сервере Beam включите поддержку Moonlight. В разделе «Пользователи → Сопряжение по PIN» введите PIN клиента и выберите пользователя, чьи права получит устройство.

Какой Android APK выбрать?

Если не знаете архитектуру устройства, выбирайте Universal. ARM64 занимает меньше места и подходит 64-битным ARM-устройствам, включая Pixel 10. Для ARM32 есть отдельный APK. Минимальная версия в манифесте — Android 5.0; работа на каждом конкретном устройстве зависит от его декодера и возможностей системы.

Какие проверки прошёл Android-клиент?

Версия 2.2.2 прошла локальную release-сборку и 36 автоматических проверок; изменения 2.2.0 включают шесть проверок клавиатуры на моделях Android 6 и 16. Ранее интерфейс и совместимость базового клиента проверялись на эмуляторах Android 5.0, Android 7.0 и Android TV, сеть ID — с Windows на локальном стенде. Подпись APK сохранена. Показ Gboard, живое подключение по ID через интернет и длительные сеансы на Pixel и физических ТВ ещё требуют проверки.
