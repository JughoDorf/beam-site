01 / Серверы

Один DNS или целый пул

Обычный DNS, DoH, DoH3 и DoT. Объединяйте серверы для резервирования или балансировки. Проверяйте доступность и время ответа.

02 / Правила

Обработка, обход, блокировка

Правила применяются сверху вниз до первого совпадения. Оставляйте локальные и корпоративные домены на исходном DNS или выбирайте отдельный сервер.

03 / Наблюдение

Запрос и его результат

Журнал показывает домен, настоящую программу (а не svchost.exe), правило и ответ. Встроенный кэш учитывает TTL, чтобы повторно использовать ещё действующие ответы.

04 / Привычная работа

Служба и значок в трее

DNS-движок работает отдельно от окна. Есть импорт конфигурации YogaDNS и экспорт настроек. Приложение бесплатно и не требует регистрации.

05 / Программы

Свои правила для приложений

Ограничьте правило программами: выберите их из запущенных или готовым профилем — «Браузеры», «ИИ», «Игровые платформы», «Мессенджеры», «Почта». Например, только ИИ-приложения через отдельный DNS.

06 / Надёжность

Интернет без перебоев

Если выбранные DNS-серверы перестали отвечать, запросы временно идут через DNS Windows. Неотвечающий сервер пропускается и проверяется снова. Об этом сообщают журнал и значок в трее.

07 / ИИ

Только ИИ — сервер выбирается сам

ChatGPT, Claude, Gemini и другие ИИ-сервисы идут через встроенные серверы для ИИ. BeamDNS сам проверяет, какой сервер открывает каждый сервис, и показывает выбор над журналом. Остальные сайты работают как без BeamDNS.

08 / Рядом с VPN

Не мешает другим подключениям

Порт 53 остаётся свободным, запросы VPN-клиентов и других DNS-программ не трогаются. Закрыли BeamDNS — DNS выключен.

09 / Для всех

Одни настройки на компьютер

Любой пользователь, даже без прав администратора, меняет настройки, включает BeamDNS и может удалить программу.

Без смены DNS адаптеров

Правила работают
поверх обычного DNS.

BeamDNS перехватывает исходящие UDP-запросы на порт 53 через WinDivert. Дальше запрос обрабатывается выбранным сервером, пропускается без изменений или блокируется.

Что важно знать

  • Встроенный DoH браузера и DNS по TCP не перехватываются.
  • BeamDNS не является VPN и не меняет маршрут интернет-соединения.
  • Одновременный DNS-перехват с YogaDNS не поддерживается.
  • После загрузки Windows перехват включается с задержкой 30 секунд. До этого DNS работает без правил.
  • Раздельное туннелирование ограничено кэшем DNS Windows: он общий для всех программ.
  • Серверы для ИИ — сторонние сервисы: что они открывают, зависит от сети.

Частые вопросы.

Это стабильный выпуск?

Нет, 0.10.0-beta.4 предназначена для тестирования. В проекте пройдены автоматические проверки, но работа на всех компьютерах, версиях Windows и в корпоративных сетях ещё не подтверждена.

Зачем нужны права администратора?

Они требуются для установки службы и драйвера перехвата DNS. Драйвер WinDivert входит в комплект. Окно программы и DNS-движок работают отдельно.

Нужно ли устанавливать .NET?

Интерфейс и установщик используют .NET Framework 4.8. Он уже есть в Windows 11 и обновлённых версиях Windows 10; в старой Windows 10 его может потребоваться установить. Современный .NET Runtime для DNS-движка не нужен.

Работает ли BeamDNS на Android или ARM64?

Этот выпуск предназначен для Windows x64. Версии для Android и Windows ARM64 не опубликованы.

Чем BeamDNS отличается от Beam?

Beam — удалённый доступ к компьютеру. BeamDNS — управление DNS-запросами на Windows. Это отдельные программы одного бренда Project Beam.
