# Project Beam — сайт программ

Публичный сайт: https://jughodorf.github.io/beam-site/
Бренд — Project Beam; программа — Beam. Статический GitHub Pages без npm,
трекеров и клиентских ключей. Основной репозиторий с историей остаётся закрытым;
соответствующие исходники и программы публикуются в Releases этого репозитория.

## Стабильный канал

Главная `index.html` — каталог программ Project Beam. `beam.html` — удалённый
доступ Beam; `beamdns.html` — отдельная страница DNS-менеджера BeamDNS.
`assets/products.js` переносит прежние закладки `/#beam-installer`, `/#easytier`
и другие разделы Beam на `beam.html` с сохранением якоря. Без JavaScript на
главной доступны ссылки на страницу и установщик Beam.

BeamDNS 0.9.0-beta.4 опубликован отдельным prerelease `beamdns-v0.9.0-beta.4`.
Его файлы и SHA-256 находятся в `beamdns-downloads.json`; этот каталог не меняет
`downloads.json` и канал обновлений Beam. Не отмечать релиз BeamDNS как Latest:
последним стабильным выпуском Beam остаётся v2.2.4. Публикуется предоставленный
установщик, инструкция, примечания, лицензии и соответствующие исходники WinDivert.
Исходники самого приложения BeamDNS не публикуются автоматически.

Основной выпуск — v2.2.4: Windows Server/Client и общий установщик 2.2.4,
Beam Connect 0.1.6. Android 2.2.4 (код версии 13), подписан прежним ключом. Модуль 0.1.6 и его исходники сохранены из v2.2.3. Общий установщик — основной, отдельные компоненты — дополнительные.
`downloads.json.files` содержит стабильные файлы с точными размерами и SHA-256;
`stable` — сведения выпуска и отдельные версии платформ; `stable.sources` — имена
трёх соответствующих архивов текущего комплекта. `sources` — архивы и история.
Прежний `preview` сохранён для совместимости; его файлы и прошлые Releases не меняются.
Windows-проверка обновлений учитывает стабильные файлы и при включённом preview-канале.

Стабильный канал выбран владельцем проекта. Это не заявление, что все сочетания
Wi-Fi, GPU, HDR и мониторов проверены: реальные игровые задержки продолжаем проверять.
Фильтр звука приложений включается отдельно; медиатракт Apollo/Moonlight сохранён.
Не включать приглашения сети, личные профили или ключи подписи в публичные файлы.

## Проверка и публикация

`python scripts/check_site.py`, `node --check assets/site.js`, затем локальная
проверка браузером. Бинарные файлы и архивы сначала загружаются в draft Release,
сверяются размеры и SHA-256. После публикации стабильного Release обновляется main
сайта; GitHub Pages автоматически разворачивает его. Открытые скачивания проверяются
без входа в GitHub. Исходники программ публикуются по GPL/LGPL с лицензиями и атрибуцией.

## Каталог узлов Beam Connect

`easytier-nodes.txt` — кандидаты публичных bootstrap-узлов, не гарантия доступности
или скорости ретрансляции. Клиент проверяет реальное подключение и использует общий
набор сети. Данные не содержат пользователей Beam, VPN-идентичностей и приглашений.
Сохранены шесть общих узлов; вместимость 256 адресов не означает, что все они
одновременно существуют или проверены. Ссылки операторов: https://github.com/pmh1314520/MCTier,
https://wiki.slarker.me/application/easytier.html и https://easytier.dreamlife.indevs.in/.
Перед изменением списка проверяйте протокол и запускайте проверку сайта.
